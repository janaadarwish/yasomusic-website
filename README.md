
# 🎵 Yaso Music Website

A music portfolio website built with HTML, CSS, and Bootstrap to showcase Yaso Music's creative work and online presence.

🌐 **Live Website:** [yasomusicco.com](https://yasomusicco.com/index.html)

## ✨ Features

- Responsive music portfolio website
- Clean and user-friendly interface
- Dedicated pages for content, portfolio, and contact
- Organized media assets and styling
- Published and accessible through a custom domain

## 🛠️ Built With

- HTML5
- CSS3
- Bootstrap
- JavaScript

## 📂 Project Structure

```text
yasomusic-website/
├── assets/
├── css/
├── js/
├── webfonts/
├── index.html
├── content.html
├── protofolio.html
└── contact.html
```

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/janaadarwish/yasomusic-website.git
   ```

2. Open the project folder:

   ```bash
   cd yasomusic-website
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
